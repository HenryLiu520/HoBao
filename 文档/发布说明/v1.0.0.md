## v1.0.0 · 自动联网更新汇率

汇率从「手动填写的常量」变成「每日自动同步 + 缓存降级」——
这是账本算法层面的变化，所以进第一位版本号。

### 新增

- **自动联网更新**（可选，**默认关闭**）
  - 打开后后台**每天**拉一次（WorkManager，要求有网才跑）
  - 也可以点「立即更新」手动触发
- **两个源自动降级**：`latest.currency-api.pages.dev`（新鲜）→ `jsDelivr`（兜底）
- **按数据日期缓存**：缓存 key 用响应里的 `date` 字段，不是本地时间
- **失败不装成功**：两个源都挂时退回上一次的缓存，界面上明确显示
  「网络不可用，用的是 YYYY-MM-DD 的数据」—— 不静默返回空值或 0
- 汇率页显示**数据日期**，你知道这个数是什么时候的

### 数据与隐私

- 新增**唯一**一个权限 `INTERNET`，只用于拉汇率（一条 GET，不带任何参数、不发设备信息）
- 仍然**没有任何**统计 / 广告 / 崩溃收集 SDK，没有任何后端
- 不打开这个开关时，app 的行为和纯离线版完全一样

### 精度

- 网上拿到的汇率**存全精度**（8~9 位有效数字），界面仍显示两位
  - 原因：把 USD 截成 `0.15` 会让每笔美元账差 0.44%
- 金额换算仍然走整数最小单位，只在最后舍入一次

### 升级说明

- `versionCode 3`，**签名与 v0.4 相同** —— 可以直接覆盖安装，数据不会丢
- 升级后去「设置 → 汇率」打开开关即可

### 内部

- 新增 14 个离线单元测试（解析 / 降级 / stale / 三角换算 / crypto 过滤）
- 联网冒烟测试默认跳过：`./gradlew test --tests "*ForexLiveSmokeTest*" -Dhobao.live=1`
