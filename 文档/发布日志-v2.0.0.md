# 荷包 v2.0.0

**这是荷包第一个大版本更新。** 账本从「一张表装三种钱」重构成「两本独立的账」，
并第一次有了图表分析。

> 升级**不需要做任何事**：装上去打开，旧数据自动迁移，一分钱都不会少。
> （已实测：v1.0.0 记的账 → 覆盖安装 v2.0.0 → 数字完全一致）

---

## 🆕 分析页

一个全新的页签，回答「我的钱去哪了」。

- **分类占比环形图** —— 哪个类别吃掉最多钱，一眼看到，不用翻列表
- **趋势折线图** —— 可以横向滑动回看更早的数据，不用挤在一屏里
- **横轴粒度可切** —— 日 / 周 / 月 / 季 / 年。看「这个月哪天花得凶」用「日」，
  看「今年什么时候最费钱」用「月」
- **概览三个数** —— 区间总额、笔数、日均
- 时间范围：本周 / 本月 / 本季 / 本年

两个容易被忽略但很重要的细节：

- **日均的分母只算「已经过去的天」**。10 月 20 号看本月日均，
  除的是 20 天，不是 31 天 —— 否则「这个月平均每天花多少」会被未来 11 天摊薄一半
- **换粒度不改变总数**。日粒度 20 根柱子加起来，和月粒度 1 根柱子，是同一个数

## 💰 收入：独立成一本账

以前收入和花销挤在同一张表里，靠一个标记位区分。现在**各住各的表**。

- 记一笔页顶部三段切换：**`− 支出` / `↩ 退款` / `+ 收入`**
- 回顾页顶部两个账本：**`花销` / `收入`**，一键切换
- 收入分类：工资 / 奖金 / 红包 / 利息 / 其他收入

**为什么值得为此重构整个数据模型**：账本分开之后，「花了多少」和「挣了多少」在代码里
是两条永不交叉的路。之前那种「统计时忘了过滤掉收入，总额忽然多出 5000」的错，
在新结构下**从根上不可能发生**。

---

## ↩️ 退款 / 返现：像记一笔普通账一样

以前退个款要：找到原账 → 点开 → 弹窗 → 填金额 → 填原因。
现在：**切到「退款」→ 记一笔 → 完事**。

- 退款就是一条**金额为负的花销**，落在「退款」「返现」两个分类里
- **可以选日期** —— 这个月退的上个月的东西，记在上个月
- 支持部分退款、多次退款，不需要事前登记
- 桌面组件的「今日开销」自动跟着变（负数天然抵扣）

---

## 📊 一个口径上的改进：三个数，不是一个数

这是这一版最不显眼、但最影响可信度的改动。

以前退款会让「本月支出」这个数字变小 —— 极端情况下，一个只退款、没花钱的月份，
「本月支出」会变成 **负数**。而「花了 −20 元」是一句没有意义的话。

现在每个区间的汇总给**三个数**：

```
支出合计   CNY 884.89     ← 永远是正数
退款合计   CNY -20.00
净额       CNY 864.89     ← 这个可以是负的，它就该是负的
```

- 「支出」这个数按定义 **永远 ≥ 0**
- 负号只出现在它该出现的地方：退款合计、净额、以及趋势图上向下掉的柱子
- 只退不花的月份显示成 `支出 CNY 0.00 · 退款 CNY -20.00 · 净 CNY -20.00`，
  读起来完全说得通

## 💾 备份格式升到 v3

- **导出包含收入**（以前只导花销）
- **退款跟着花销一起走**（以前导出的备份里根本没有退款，恢复之后净额会变回毛额 —— 这个坑补掉了）
- **v1 / v2 的旧备份文件依然能导入**，会自动升级格式

**升级实测**（v1.0.0 的数据库 v2 → v2.0.0 的 v5，三段迁移连着跑）：

- 升级前记 2 笔：`CNY 42.50` + `CNY 8.00` = `CNY 50.50`
- 覆盖安装（不卸载、不清数据）
- 升级后：本月支出仍然 `CNY 50.50`，回顾页两笔都在
- 升级后立刻记一笔退款 20：`支出 50.50 / 退款 -20.00 / 净 30.50`
- **崩溃 0 次**
