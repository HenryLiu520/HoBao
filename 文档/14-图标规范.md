# 14 · 图标规范

> 2026-10-19 · 定下「以后所有图标从哪来」，避免三个月后 app 像拼贴的

---

## 一、选定：Material Symbols Outlined

**许可证：Apache 2.0**（可商用、可改、无署名要求）

选它的理由不是"名气大"，是**它和 Material 3 是同一套网格**：

| 参数 | 值 |
|---|---|
| 画布 | 24dp |
| 视窗 | 960 单位 |
| 笔画重量 | 400（Regular） |
| 端点/圆角 | 统一的 4 单位圆角 |

只要所有图标都来自这里，**风格天然统一**，不需要靠眼睛去对。

### 为什么不选别的

| 候选 | 为什么不用 |
|---|---|
| **Lucide**（MIT，Feather 后继） | 好看，但它是 2 单位**描边**风格。和 Material 的**实心**图标放在一起，一个界面里会"一半线一半块"，比不统一更刺眼 |
| **Tabler Icons**（MIT，5000+） | 同上，描边派 |
| **Phosphor**（MIT，多字重） | 质量高，但它的"bold/fill"变形和 Material 的实心不是一回事；混用要重做整套 |
| **自己画** | 第一个漏斗（`ic_filter.xml`）就是手画的 —— 形状像了，但笔画重量和圆角跟 Material 对不上，**放大一倍就露馅**。已删除 |

> 结论：**图标这种东西，要么全套换，要么一个都别自己画。**

## 二、三个来源，一条规矩

| 来源 | 什么时候用 | 例子 |
|---|---|---|
| `Icons.Filled.*` / `Icons.Outlined.*`（Compose core，约 50 个） | 图标在 core 里就**直接用**，不要下载 | `Icons.Filled.Check`、`Icons.Filled.Settings` |
| `res/drawable/ic_<symbol>.xml`（脚本下载） | core 里没有的 | 漏斗 `ic_filter_alt` |
| ❌ 手写 `<vector>` | **永远不要** | — |

Compose core 里的图标本来就是 Material 家族的，和 Symbols 只差细微版本，**在同一个界面里混用不违和**；
真正会坏事的是"自己描一个"。

## 五、用的时候的规矩

```kotlin
Icon(
    painter = painterResource(R.drawable.ic_filter_alt),
    contentDescription = "筛选",                      // 无障碍必填；装饰性图标写 null
    tint = MaterialTheme.colorScheme.onSurfaceVariant, // 颜色永远靠 tint
)
```

- **颜色不进文件**。XML 里 `android:fillColor="#FF000000"` 是**占位**，实际颜色由 `tint` 决定 ——
  这样同一个图标在深色/浅色、选中/未选中都能复用。
- **尺寸靠外层**。Compose 的 `Icon` 默认 24dp；RemoteViews 里用 `android:layout_width` 定。
  **不要改 viewport**，改了笔画粗细就跟着变。

## 六、一个必踩的坑：Material Symbols 的坐标系

SVG 返回的是：

```xml
<svg viewBox="0 -960 960 960">
```

**y 从 −960 到 0**。而 Android 的 `<vector>` viewport 从 0 开始 ——
直接照搬坐标，图标会画在**画布上方**，屏幕上就是一片空白（"图标没了"，但日志毫无异常）。

所以脚本会包一层：

```xml
<vector android:viewportWidth="960" android:viewportHeight="960">
    <group android:translateY="960">     <!-- ← 整体下移一个画布高 -->
        <path ... />
    </group>
</vector>
```

**手改这些文件时，千万别把 `<group>` 删了。**

## 七、以后加图标的流程

1. 去 fonts.google.com/icons 查名字
2. `python3 tools/fetch_material_symbols.py <名字>`
3. 界面里 `painterResource(R.drawable.ic_<名字>)`
4. **不要**改生成的文件（文件头写了"自动生成"）
5. 要换形状 → 换名字重跑脚本，不是在文件里改坐标
